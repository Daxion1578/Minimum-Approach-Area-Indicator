## 書き出す

ffmpeg と Python（numpy・Pillow）が要る。フォントは `fonts/` に同梱（BIZ UDPGothic／BIZ UDGothic、SIL OFL 1.1）。

```sh
cd scripts/demo_video/v8
python compose8.py shizuka --at C7:6.0           # カットの中の秒を指定して 1 コマ → out/v8-C7-006.0.png
python compose8.py shizuka --frames C6,C7        # 各カットの 3 か所
python compose8.py shizuka --res 720 --jobs 3    # 確認用の通し（約 1.5 分）
python compose8.py shizuka --res 1080 --jobs 3   # 提出用（約 2.5 分）→ out/maai-v8-shizuka-1080p.mp4
bash qa.sh out/maai-v8-shizuka-1080p.mp4 out/qa  # 尺・形式・音量・端の黒・2 秒おきのコマ一覧
```

最後に「点検: 字の大きさ・はみ出し・字幕との重なり 問題なし」と出れば、1080p で 36px 未満の字・画面からはみ出す字・字幕に重なる字は無い（C1 の札が画面の外から滑り込む所は「はみ出す字」に出るが、動きのため）。

## 直す所

- 語りの文と間: `scripts/shizuka.txt`（空行で段落＝カット、`<#秒#>` は無音）。直したら `python narr.py shizuka --only 6`（6 番目の段落だけ作り直す。字幕の時刻 `audio/shizuka/timing.json` も更新される）。読みの確認は `--kana`。読み違いは narr.py の `SAY` に足す。
- カットの長さ: compose8.py の `SPEC`（最小の長さ、語りの前、語りの後）。
- 録画のどこを使うか・どこへ寄るか: `plan_c5`〜`plan_c8`。`segs` は（カットの秒, カットの秒, 録画の秒, 録画の秒）、`zooms` は（カットの秒, 録画の範囲 1920×1080 の画素）。2.2 倍を超えて速めた所には自動で「早送り」が付く。
- 画面に足した枠・数字: `over_c5`〜`over_c8`、作った場面は `c1`〜`c4`・`c9`・`c10`。
- 音: `bgm8`（冒頭は低い持続音、C4 の名前から明るい曲）、`mix_audio`（語り −20 dBFS、曲は 15 dB 下、語りの間は 7 dB 下げる）。最後に −16 LUFS へそろえる。

## 語りを作り直すとき（VOICEVOX core 0.15）

Linux の場合。VOICEVOX/voicevox_core のリリース 0.15.0 から `voicevox_core-0.15.0+cpu-cp38-abi3-linux_x86_64.whl` と `voicevox_core-linux-x64-cpu-0.15.0.zip`、r9y9/open_jtalk のリリース v1.11.1 から `open_jtalk_dic_utf_8-1.11.tar.gz` を取り、次の形に置く（`vv/` はコミットしない）。

```sh
cd scripts/demo_video/v8
python -m venv vv/venv && vv/venv/bin/pip install voicevox_core-0.15.0+cpu-cp38-abi3-linux_x86_64.whl
unzip voicevox_core-linux-x64-cpu-0.15.0.zip -d vv/ && mkdir -p vv/dic && tar xzf open_jtalk_dic_utf_8-1.11.tar.gz -C vv/dic
cat > vv/vv <<'SH'
#!/bin/sh
D=$(cd "$(dirname "$0")" && pwd)
LD_LIBRARY_PATH="$D/voicevox_core-linux-x64-cpu-0.15.0" exec "$D/venv/bin/python" -I "$D/../tts.py" "$@"
SH
chmod +x vv/vv
python narr.py shizuka --kana   # 読みだけ確かめる
```

Windows で core を入れない場合は、VOICEVOX アプリで同じ声（冥鳴ひまり、話速 1.03、抑揚 1.12）の段落を書き出し、`override/shizuka/p06.wav` のように置いて `python narr.py shizuka --only 6` を回す（core は呼ばない。字幕の時刻は文字数で按分になる）。
