# 動画の台本（3 分）

画面収録＋語り。映すのは実際に動く画面と、はっきり「構想」と示した 3D の映像だけ。実在の設備・写真・社名は映さない（画面に出る図面・名称はすべて合成データ）。

組み立ては短い紹介動画の定石に合わせる: 問題を自分の言葉で → 一つの場面を最初から最後まで通す → 仕組みと検証 → この先 → 込めた思い。語りは一人称で、数字と固有名は画面に出るものだけを言う。

収録前の準備:
- `uvicorn server.app:app`（または公開のブラウザ版）、ブラウザは 1440×900 以上、ステップ 1（図面取込）を開いた状態で開始。`.env` にキーがあれば図面取込の画面に「Claude: …」と出る。無ければ「規則で代替」の表示のまま収録し、語りでそう言う。
- 締めの札と現地表示の構想の映像は（語り v4 では題の札は使わず、図面から始める）、ブラウザの別タブで開いて全画面にして映す（編集ソフトは要らない）。
  - 札: `python scripts/ar_concept/render.py --card title --out title.png`、`--card closing --out closing.png`（または `scripts/ar_concept/cards.html?card=title` をそのまま開く）
  - 映像: `python scripts/ar_concept/dump.py && python scripts/ar_concept/render.py --out ar-concept.mp4`（1920×1080）。収録では 30 秒すべて使う。再生の前に一時停止で頭出ししておく

## 画面操作のメモ

- 見本は 66kV 1 号ダイヤの遮断器（6T-110）。重さだけなら 10t 級、最小の停止範囲では離隔のために 35t 級、1 号変圧器を追加で止めれば 20t 級（条件付き可）になる（`python scripts/check_demo.py` の 3・4 と同じ。クラスは 4.9t〜100t 級の 10 段、例示値）
- 装置図の下書きは、ステップ 1 の「サンプル装置図で試す」（見当たらなければ「詳しく」の引き出しの中）。左が合成データ、右が図面から起こした 3D。要確認は読み上げず見せるだけにし、「この 3D で続ける」（要確認があれば「要確認 n 件を確認のうえ続ける」）を押す。押すと 3D 見出しのバッジが変わる
- 停止範囲の結線図は右上の小窓に出る。「拡大」で寄る。停止範囲を作ると対象の位置へ自動で寄る
- 3D の視点ボタン: 全体／対象へ寄る／クレーンへ寄る。配置を採用すると自動でクレーンへ寄る
- 「詳しく」の引き出しと JSON の列は、根拠を見せる 2:00–2:20 以外は閉じておく
- 重機では、地面の緑のます目＝クレーンを据えてよい範囲。緑を押すとクレーンがそこへ移って判定し直される。一つ上・二つ上の級とも比べられる
- 承認の後、ステップ 4（計画確定）の一覧から step-1-sld.pdf（停止範囲図）と plan-crane.pdf（クレーン配置の平面図）を順に開く
- 構想映像の中の計画は、ステップ 3・4 で承認したものと同じ engine の出力。作り直すときは `python scripts/ar_concept/dump.py` → `render.py`。距離のラベルは engine が出した一番近い部分（今回は吊荷）を言う
- 締めの札の URL を入れない判断なら、`scripts/ar_concept/cards.html` の `.url` の行を消して札を作り直す
