# 動画の台本（3 分）

画面収録＋語り。映すのは実際に動く画面だけ。実在の設備・写真・社名は映さない（画面に出る図面・名称はすべて合成データ）。

収録前の準備: `uvicorn server.app:app`、ブラウザは 1440×900 以上、タブ 1 を開いた状態で開始。`.env` にキーがあれば取込タブ右上が「Claude: …」になる。無ければ「規則で代替」の表示のまま収録し、語りでそう言う。

## 秒割り

| 時間 | 画面 | 語り |
|---|---|---|
| 0:00–0:20 | タイトル → 3D 全体（通常状態、全部赤） | 機器を取り替えるとき、変電所は全部は止められません。隣に電気の流れる線が残り、そこへクレーンが入ります。近づいてはいけない距離は、図面に描かれていない。MAAI、間合い。見えない間合いを、見えるようにします |
| 0:20–0:50 | タブ 1。PDF を選ぶ → 取り込む → 開閉器が番号で並ぶ → 質問が 9 つ → 「質問の無いものを確認済にする」 | 入口は図面です。単線結線図の PDF を投げ込むと、線と記号と番号から接続を起こします。接続を決めるのは計算。Claude は番号の形とつながりから種別を確かめ、迷った点を人への質問にします。ここでは新設予定のベイが 9 つ、質問として残りました。人が確認して、はじめて使えるようになります |
| 0:50–1:20 | タブ 2。対象「2号変圧器」→ 停止ステップを作る → 段階 1・2・3 を順に押す（視点は対象に寄る） | 取り替える機器を選ぶと、遮断器を切り、断路器を両側で切り、接地する、という停止ステップが出ます。段階を進めるたびに、どの導体が生きているかを計算し直す。赤が課電、緑が停電して接地、黄は止めたが接地していない区間。黄は既定で課電扱いです。迷ったら保守側に倒す |
| 1:20–1:50 | タブ 3。離隔を判定する → 不可。表の最小 3.00 m／必要 5.20 m。「クレーンへ寄る」 | クレーンを置きます。旋回を掃引し、ブームと吊荷が残った充電部にどこまで近づくかを、導体ごと相ごとに出す。結果は不可。3号変圧器の一次に 3 メートル、必要は 5.2 メートル。根拠は数字で出ます |

## 切る順（時間が足りなければ）

1. 2:40 以降の仕組みの説明を 10 秒に
2. 段階 1・2 を飛ばして段階 3 だけ
3. 取込の「確認済にする」操作を省き、取込結果の一瞬だけ

## 画面操作のメモ

- クレーンの初期値は「段階 3 で不可、起伏角 65° で可」になるように置いてある（ベース 88,72、向き 0°、ブーム 14 m、起伏 45°、旋回 ±50°）。変えない
- 3D の視点ボタン: 全体／対象へ寄る／クレーンへ寄る。停止ステップを作ると自動で対象に寄る
- 右の JSON 列は映さなくてよい。映すなら energization.json の `state` が変わる瞬間
