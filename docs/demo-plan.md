# 動画の台本（3 分）

画面収録＋語り。映すのは実際に動く画面だけ。実在の設備・写真・社名は映さない（画面に出る図面・名称はすべて合成データ）。

収録前の準備: `uvicorn server.app:app`（または公開のブラウザ版）、ブラウザは 1440×900 以上、タブ 1 を開いた状態で開始。`.env` にキーがあれば取込タブ右上が「Claude: …」になる。無ければ「規則で代替」の表示のまま収録し、語りでそう言う。

## 切る順（時間が足りなければ）

1. 2:25 以降の仕組みの説明を 10 秒に
2. 取込の「確認済にする」操作を省き、取込結果の一瞬だけ
3. 結線図で開閉器を押す操作を省く

## 画面操作のメモ

- 見本は 66kV 1 号ダイヤの遮断器（6T-110）。最小の停止範囲では 50t 級、1 号変圧器を追加で止めれば 25t 級になる（`python scripts/check_demo.py` の 3・4 と同じ）
- 結線図は右上の「拡大」で寄る。停止範囲を作ると対象の位置へ自動で寄る
- 3D の視点ボタン: 全体／対象へ寄る／クレーンへ寄る。配置を採用すると自動でクレーンへ寄る
- 右の JSON 列は映さなくてよい
