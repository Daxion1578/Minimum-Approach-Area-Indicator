# 動画の台本（3 分）

画面収録＋語り。映すのは実際に動く画面と、はっきり「構想」と示した 3D の映像だけ。実在の設備・写真・社名は映さない（画面に出る図面・名称はすべて合成データ）。

組み立ては短い紹介動画の定石に合わせる: 問題を自分の言葉で → 一つの場面を最初から最後まで通す → 仕組みと検証 → この先 → 込めた思い。語りは一人称で、数字と固有名は画面に出るものだけを言う。

収録前の準備:
- `uvicorn server.app:app`（または公開のブラウザ版）、ブラウザは 1440×900 以上、タブ 1 を開いた状態で開始。`.env` にキーがあれば取込タブ右上が「Claude: …」になる。無ければ「規則で代替」の表示のまま収録し、語りでそう言う。
- 題の札・締めの札・現地表示の構想の映像は、ブラウザの別タブで開いて全画面にして映す（編集ソフトは要らない）。
  - 札: `python scripts/ar_concept/render.py --card title --out title.png`、`--card closing --out closing.png`（または `scripts/ar_concept/cards.html?card=title` をそのまま開く）
  - 映像: `python scripts/ar_concept/dump.py && python scripts/ar_concept/render.py --out ar-concept.mp4`（1920×1080）。収録では 27 秒で止める。再生の前に一時停止で頭出ししておく

## 秒割り

| 時間 | 画面 | 語り |
|---|---|---|
| 0:00–0:20 | 題の札 → 3D 全体（平常、全部赤） | 機器を取り替える日も、変電所は全部は止められません。すぐ隣に電気が流れたままの線が残り、そこへクレーンが入ります。どこまで近づけていいかは図面に書いてなくて、私も平面図に円を描いて、こんな感じかな、で決めていました。それを見えるようにする道具が、間合い、MAAI です |
| 0:20–0:50 | タブ 1。単線結線図を取り込む →「サンプル装置図で試す」→ 左右の 3D と一致の表 →「この 3D で続ける」（要確認があれば「要確認 n 件を確認のうえ続ける」）→ 3D 見出しのバッジが「図面から起こした配置」に変わるのを 2 秒見せる | 入口はいつもの図面です。単線結線図から機器のつながりを、装置図の平面と断面から機器の位置と高さを読んで、構内の 3D を組み立てます。Claude は記号の種類を確かめて、迷ったところを人への質問にします。読めなかったところは要確認として残り、人が確認して「この 3D で続ける」を押してはじめて、計算に使われます |
| 0:50–1:15 | タブ 2。対象 6T-110 のまま「停止範囲を作る」→ 結線図を拡大 → 開閉器を一つ押して赤 → 戻す | 今日取り替えるのは 66kV の遮断器です。対象を選ぶと、電気が流れ込んでくる側すべてで最初の断路器まで切る、という停止範囲が出ます。結線図の緑が停電、赤が充電です。開閉器を押すと、その場で塗り替わります。接地を取ることは、計画の条件として必ず書き出します |
| 1:15–1:50 | タブ 3。「一番小さいクレーンを選ぶ」→ 重さだけなら 10t 級、離隔のため 35t 級、一つ下が使えない理由 →「追加停止を採用して 20t にする」→ 条件付き可 | 次にクレーンです。取り替える機器の真上と資材置場の真上、この 2 点と重さだけなら 10t 級で足ります。でも充電部から 4 m 離すには 35t 級が要る。一つ下は、1 号変圧器の線に近づきすぎて使えません。では、その変圧器も止めたらどうか。計算すると 20t 級で済み、監視員を置く条件付きで可になります。止めるかどうかは、人が決めます |
| 1:50–2:13 | タブ 4。条件 →「承認して書き出す」→ 停止範囲図 PDF → クレーン配置の平面図 PDF（plan-crane.pdf、5 秒） | 最後に承認です。承認するのは人で、押した瞬間にもう一度判定し直します。不可の計画と、クレーンのない計画は承認できません。書き出されるのは、停止範囲を塗り分けた単線結線図と、クレーンの据付位置を描き込んだ一般平面図。工事会社にそのまま渡せる形です |
| 2:13–2:21 | 黒地 3 行の静止画 | 安全の判断は計算で行い、説明は Claude が書き、採否は人が決める。この分担で作っています |
| 2:21–2:48 | 構想映像（27 秒で止める。右上「構想のイメージ・未実装」が出続ける） | この先は現地です。承認した計画をスマホでかざすと、映った機器を 3D と照らし合わせて位置を合わせ、合ったところだけに近づけない範囲を重ねます。位置が決まらないときは出しません。取り違えが一番危ないからです。充電しているかどうかはカメラで当てず、図面と開閉器の状態から計算で決めます |
| 2:48–3:00 | 締めの札（12 秒） | 現場の安全を、見張りの目と経験者の頭の中だけに置きたくない。人が替わっても同じ答えにたどり着ける道具にしたくて、作りました |

## 切る順（時間が足りなければ）

1. 2:13–2:21 の黒地の静止画を 5 秒に（「採否は人が決める」だけ）
2. 取込の「この 3D で続ける」の後のバッジ確認を省く
3. 結線図で開閉器を押す操作を省く
4. 構想映像を 20 秒で止める（クレーンの場面の前）

## 画面操作のメモ

- 見本は 66kV 1 号ダイヤの遮断器（6T-110）。重さだけなら 10t 級、最小の停止範囲では離隔のために 35t 級、1 号変圧器を追加で止めれば 20t 級（条件付き可）になる（`python scripts/check_demo.py` の 3・4 と同じ。クラスは 4.9t〜100t 級の 10 段、例示値）
- 装置図の下書きは、タブ 1 の「サンプル装置図で試す」。左が合成データ、右が図面から起こした 3D。要確認は読み上げず見せるだけにし、「この 3D で続ける」（要確認があれば「要確認 n 件を確認のうえ続ける」）を押す。押すと 3D 見出しのバッジが変わる
- 結線図は右上の「拡大」で寄る。停止範囲を作ると対象の位置へ自動で寄る
- 3D の視点ボタン: 全体／対象へ寄る／クレーンへ寄る。配置を採用すると自動でクレーンへ寄る
- 右の JSON 列は映さなくてよい
- 承認の後、タブ 4 の一覧から step-1-sld.pdf（停止範囲図）と plan-crane.pdf（クレーン配置の平面図）を順に開く
- 構想映像の中の計画は、タブ 3・4 で承認したものと同じ engine の出力。作り直すときは `python scripts/ar_concept/dump.py` → `render.py`
- 締めの札の URL を入れない判断なら、`scripts/ar_concept/cards.html` の `.url` の行を消して札を作り直す
