# AR 位置合わせ検証（web/ar.html）

仕様§9-5 の試作で確かめることと、その結果。場所は駐車場・公園など。実際の構内では撮影・検証しない（仕様§0）。

## 開き方

- Android の Chrome で `web/ar.html` を https の URL で開く（GitHub Pages など）。ファイルを直接開いても AR は動かない。
- 初回は「Google Play 開発者サービス（AR）」の導入を求められることがある。
- 表示する包絡は `web/sample/SITE-01.envelope.json`（`python scripts/make_ar_sample.py` が engine で計算して書き出す。状態 normal・未承認、離隔は目安値で要確認）。別の状態は `python scripts/make_ar_sample.py tr2-outage` のように作り直すか、画面の「読み込む」から入れる。
- 基準点は `data/sites/SITE-01/truth/layout.json` の `reference_points`（P1–P2 は 40 m）。狭い場所では、P1→P2 の線上で 20 m・10 m・5 m の点を B にできる。

## 手順

1. 平らで開けた場所に、画面で選んだ間隔（既定は P1→P2 の 20 m 点）でテープを2か所貼る。A→B の向きが図面の向きになる。
2. 「ARを開始」を押し、地面に照準の白い輪が出るまでカメラをゆっくり動かす。
3. A のテープの中心に照準を合わせて「Aを記録」。B へ移動し、同じように「Bを記録」。
4. 真下線（地面の破線）が A–B のテープを結ぶ線に乗るか、高所の母線と包絡を見上げて追えるかを見る。
5. 10〜20 m 歩いて戻り、テープに照準を合わせて「ずれを記録」。対象の基準点を変えて何回か繰り返す。
6. 「記録をコピー」で出る表を、下の「記録」に貼る。

## 確かめること

| 項目 | 目安 | 結果 |
|---|---|---|
| 床面検出 | 照準の輪が数十秒以内に出る | |
| 基準点2点での位置合わせ | 画面の「テープ間の差」が 0.1 m 以内 | |
| 高所カプセルの表示 | 220kV A母線（高さ 10.5 m、S相がテープを結ぶ線の真上）と包絡を見上げて追える | |
| 10〜20 m 歩行後のずれ | 水平 0.5 m 以内（仕様§16 の仮置き） | |
| メジャー実測との誤差 | B へ向かうときの「Aから◯m」の表示とメジャーの差 | |
| 屋外の明るさでの視認性 | 「包絡の濃さ」を上げれば読める | |
