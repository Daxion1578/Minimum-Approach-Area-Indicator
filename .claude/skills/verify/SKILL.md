# 手元確認の手順を出す

1. まず自分で `python -m pytest -q` を実行し、結果を1行で報告する。失敗していれば手順を出す前に直す。
2. 確認手順は、PowerShell にそのまま貼れるコマンドと、画面で何が見えれば合格か（色・数値・ファイル名）を番号付きで書く。`docs/spec.md` §15 の該当縦切りの文言に合わせる。
3. 「合格でないとき」に見る場所（エラーの出る画面、ログのパス）を1〜2行添える。
4. 専門用語は初出で一言説明する。手順は10行以内。
