# 夜の手順

1. `python -m pytest -q` を実行する。落ちていれば、直すか、直せない理由を `STATUS.md` の「確かめた結果」に書く。隠さない。
2. `/verify` の形式で、今日の縦切りの手元確認の手順を出す（本人が明日の朝に試す）。
3. 今日した判断を `docs/decisions.md` に日付つきで1〜3行追記する（何を選び、何を捨て、なぜか）。
4. 新しく Claude の使い方を増やしたなら `docs/claude-boundary.md` に1行足す（「なぜそれか」が書けないなら足さない）。
5. サブエージェント `task-keeper` を呼び、`TASKS.md` を更新させる。
6. `/report` で `STATUS.md` を上書きする。批評の合計点を「確かめた結果」に1行入れる。
7. `/publish-check` を通す。
8. コミットする（メッセージは日本語で「何を・なぜ」）。
9. 「push してよいか」を本人に聞く。了承されるまで push しない。

ターミナルに出すのは、結論1行と「STATUS.md を更新しました。push してよいですか」だけ。
