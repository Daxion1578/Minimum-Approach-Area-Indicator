# 縦切りの進め方

1. `docs/spec.md` の §14（日割り）と §15（完成の定義）、`docs/decisions.md` の直近を読み、今日の日付で着手すべき縦切りを特定する。前の縦切りの確認手順が通っていなければ、そちらを先にする。
2. 着手前に、作るファイル・テスト・確認手順を5行以内で示し、私の了承を得る。仕様と食い違う点や §16 の未決事項に触れる場合は、ここで選択肢と推奨を出す。
3. 実装は「契約（スキーマ）→ テスト → エンジン → 表示」の順。`engine/` の値を Claude 層で決めない。
4. 30分程度の単位で区切り、テストが通る状態でコミットする（メッセージは日本語、何を・なぜ）。
5. 縦切りの最後に `/verify` の形式で手元確認の手順を出す。
6. 判断をしたら `docs/decisions.md` に日付つきで1〜3行追記する。
7. 時間枠を超えそうなら、§14 の「夜の判断」に沿って削る候補を示し、私に決めてもらう。
