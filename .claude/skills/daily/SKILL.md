# 朝の手順

本人はスマホの GitHub で `STATUS.md` を見る。この手順の目的は、本人が「今日の一つ」に「やって」と答えるだけで作業が始まる状態にすること。

1. `/critique` を実行し、`docs/critique/<MMDD>.md` を書く（コードは触らない）。
2. サブエージェント `task-keeper` を呼び、`TASKS.md` を更新させる。
3. `TASKS.md` の「今日の一つ」を、`/slice` の形式で計画に落とす（作るファイル・テスト・手元確認の手順を5行以内）。選択肢が複数あるなら2〜3個と推奨。
4. `STATUS.md` の「判断してほしいこと」に、未決のものがあれば選択肢の表で残す（`/report` の型に従う）。
5. ここで止まり、本人の了承を待つ。了承されたら `/slice` の手順で着手する。

ターミナルに出すのは、批評の合計点1行と、今日の一つ（選択肢があれば番号付き）だけ。
