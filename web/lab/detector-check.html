端末内の検出器（YOLO-World）が写真の中で何を見つけるかを確かめます。写真もモデルもこの端末の中だけで使い、どこにも送りません。

モデル

未設定

モデルは GitHub Actions の成果物（zip）の中の .onnx。lab-yoloworld-export の yoloworld-s.onnx（YOLO-World・語11個）か、lab-substation-train の substation-*.onnx（公開データで学習した変電所機器15種類）。AGPL-3.0 のためリポジトリには置かない。選ぶとこのブラウザに保存され、カメラAR でも使える。実行部品（onnxruntime-web 1.20.1、約22MB）は jsDelivr から取り、ハッシュで照合してから使う。

写真

0.25

下限を下げると、自信の低い枠も出る（誤りも増える）。下限は検出し直さずに変えられる。遠くの小さな物は「細かく見る」で拾えることがある。

実験用です。検出は候補にすぎず、見落としも誤りもあります。電気が来ているかは写真では分かりません。
